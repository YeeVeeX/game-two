# A0.5 Kit Specials + Pack Mark Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one possession-only special per pack kit plus a persistent focus-target mark, so
cast -> swap -> cast becomes a readable, situational pack combo without adding gambits or a
resource meter.

**Architecture:** `Creature` keeps one shared action state machine, generalized by
`current_action` (`:attack` or `:special`) and action-owned frame/data lookup. `World` resolves
the active action through one dispatcher, with a per-victim hit registry for tile actions,
one-shot triggers for projectiles/dashes/Volley, World-owned delayed Volley impacts, and
Pack-owned mark state consumed by the existing AI view. `GridWalker#plan_dash` is the single
authoritative dash scan used by dodge, knockback, and Lunge.

**Tech Stack:** Ruby 3.4.10, Gosu 1.4.6, minitest, JSON balance data, deterministic Gosu replay
harness, Bedrock vision verdict.
