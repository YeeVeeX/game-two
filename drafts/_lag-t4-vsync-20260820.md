## 1. Investigation — how Gosu 1.4.6 sets the swap interval HERE

Installed gem source read live (`gem which gosu` →
`C:/Ruby34-x64/lib/ruby/gems/3.4.0/gems/gosu-1.4.6/`):

- **`src/Window.cpp:111` — `SDL_GL_SetSwapInterval(1);` hard-coded in
  `Gosu::Window::Window(...)`,** after `resize(...)` creates the window +
  GL context and makes it current (constructor comment) and after the
  fullscreen re-resize. Verbatim region banked: lines 95–119 (constructor:
  borderless/resizable → resize → `SDL_SetWindowPosition` → resize
  fullscreen → `SDL_GL_SetSwapInterval(1)` → update_interval + input
  wiring).
- The gem ships its own SDL: `lib/SDL2.dll` (2,296,320 bytes) beside
  `lib/gosu.so` — `gosu.so` imports it; headers at
  `dependencies/SDL/include/SDL_video.h:2093/2110` declare
  `SDL_GL_SetSwapInterval(int)` / `SDL_GL_GetSwapInterval(void)`, both
  plain-int SDLCALL — trivially FFI-able.

**Route (a) — SDL env hints: REJECTED by code inspection, not by run.**
`SDL_RENDER_VSYNC` and friends act on the SDL_Render API at renderer
creation; Gosu never creates an SDL_Renderer — it drives a raw GL context
and calls `SDL_GL_SetSwapInterval(1)` explicitly, unconditionally, AFTER
context creation. Any hint honored earlier is overwritten by that call;
`SDL_GL_SetSwapInterval` itself consults no hint. There is nothing for an
env hint to win. (The A/B's OFF run doubles as the empirical half: with no
flag and no hints, the wall pacing is intact — see §3.)

**Route (b) — post-construction FFI against the already-loaded SDL2:
CHOSEN.** `ffi (1.17.4-x64-mingw-ucrt)` is already in Gemfile.lock
(Gemfile:9 `gem "ffi", "~> 1.17"` — a real dependency, not added for
this). Mechanism: after `super` in `App::Window#initialize`, resolve the
loaded SDL2 module BY HANDLE — `GetModuleHandleA("SDL2.dll")` +
`GetProcAddress` wrapped as `FFI::Function`s — and call
`SDL_GL_SetSwapInterval(0)`. **Path-based dlopen was tried first and died
live (error 193, bad exe format): the gem ships TWO SDL2.dlls — `lib/`
holds a 32-bit vestigial `pei-i386` DLL, the live x64 one is
`lib64/SDL2.dll` (gosu.rb:6 adds `lib64` as DLL dir when RUBY_PLATFORM
matches `/^x64-/`).** The handle route removes every path assumption and
by definition talks to the loaded instance. That first ON run is banked
as `tmp/t4/on_attempt1_failed_path.log`: the FAILED line printed named
and the game ran to a clean bot quit — the never-fatal law held live,
and the run doubles as a natural control (its pacing matches OFF).
Thread/context law satisfied by construction: `#initialize` runs on the
main thread, where Gosu made the GL context current at window creation.

**Same-instance proof (designed into the boot line):** read
`SDL_GL_GetSwapInterval` BEFORE setting — only the live SDL instance whose
GL context is current on the calling thread reports Gosu's `1`; a fresh
second SDL instance would read 0 (no current context). The boot line
carries it as `was=1`.

**Route (c) — Gosu rebuild/patch: NOT NEEDED** (route (b) proves out; no
toolchain risk taken).
