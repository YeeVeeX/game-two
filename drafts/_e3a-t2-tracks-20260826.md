## Design decisions (each defensible, none in the spec's letter)

1. **The sampler rides verification run 1** — the track's source run
   is one of the two gate runs, so its chain was checked against the
   recorded chain; a separate third sampling run would be exactly the
   unchecked re-execution the gate exists to forbid (and costs a run).
2. **Record semantics pinned:** record `frame` = `world.frame` AFTER
   the producing tick; record `masks` = the consumed masks that drove
   that tick (`input_log.masks[frame-1]`). Engine-consistent with the
   digest lane (Window.tick is post-tick frame). Named in the mail.
3. **Creature reads go through `digest_fields`** — the engine's own
   canonical leaf-typed export (the digest arbiter). The track can
   never disagree with what the gate checked, and NO frozen sim file
   needed a new reader (`state_frames`/`iframes` have no public
   attr_reader; creature.rb is a frozen C2 seam — untouched).
4. **Roster = union of creatures observed in-window**; a per-tick map
   omits creatures not in play that tick (death/despawn/not-yet-
   spawned). Most information-preserving simple rule; their consumer
   adapts (their stated posture, restated in the mail).
5. **Zone-crossing windows refuse NAMED** — `zone` + `view` would lie
   past the crossing; the remedy (split the window) is in the message.
6. **`view` = the full zone rect** (`origin_px [0,0]`, map
   cols/rows × tile_size) — the headless world has no camera; the
   full-zone rect is the only self-describing choice.
7. **Constants cover exactly the roster's kits** — per-kit map (spec
   correction 3); kits absent from the window add nothing. Source =
   the verifying tree's combat.json, which the fingerprint gate just
   proved identical to the producing build ("at the bundle's
   fingerprint" holds by construction — data/** is inside the
   handshake identity).
8. **Tracks are write-once** (name collision refuses); the production
   manifest never mutates (D7) — track integrity rides the sidecar
   sha256 + the verification receipt, per spec §6 delivery grounding.

Defensive guard: `StateTrack.write` refuses an empty-window sample.
The review found it REACHABLE via `runs: 0` (vacuous-gate major, below);
with the runs<2 refusal shipped it is back to belt-and-braces — kept.
