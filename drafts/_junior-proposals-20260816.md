## Ideias propostas (Junior)

1. **Respawn**: os monstros de cada sala não deveriam renascer (ou
   renascer menos) — hoje a viagem de volta ao banco "reseta" as salas.
2. **Níveis**: usar as moedas para subir o nível dos bonecos
   (lvl 1 → lvl 2 → lvl 3...), dando sensação de progresso.
3. **Auto-ataque**: ter ataque automático, com direcionamento
   automático do alvo.
4. **IA dos aliados**: refinar para que os aliados não se joguem para
   a morte toda vez.
