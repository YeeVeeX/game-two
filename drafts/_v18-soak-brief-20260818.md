# v18 session 8 — soak design brief (2026-08-18, decisions CLOSE here)

Owner-approved automation of the multiplayer TESTING ground: a seeded
two-seat autopilot + soak orchestrator that hardens netplay+persistence
on SCRATCH saves before the humans spend real evenings on the ritual.
**A bot session is NEVER oracle evidence** — the SEVENTEENTH still needs
two real human sessions on different days + verbatim answers; nothing
here touches that surface.

## D1 — input injection: in-process autopilot, `--bot [seed]`

`App::Autopilot` is a PURE input source on the existing seam
(`update(tick)` / `down?(action)`, `src/core/input.rb` family) — the
session samples it once per executed lockstep tick exactly like a
keyboard (`Net::Session#run_tick` → `input.update(t)` +
`Protocol.mask`); solo mode gains one uniform `@input.update(frame)`
call (no-op for `KeyboardInput`). Never OS events — memorized trap:
hidden/unfocused windows must still play; SendKeys dies against focus
rules. Policy is deliberately dumb (test driver, not gameplay AI):
seeded RNG direction bursts with persistence (20–90 ticks, idle and
diagonal rolls included), fixed modular verb cadences phase-shifted by
seed (attack/dodge/special/interact/mark/swap/sustain — every legal
`Protocol::ACTIONS` bit gets exercised), quit at target tick.
Iteration cap: it moves, fights, and quits cleanly — the moment bot
behavior gets tuned for realism, stop and record.

## D2 — episode determinism: the banner line

`AUTOPILOT seed=<n> quit_tick=<n>` prints once at launch, ONLY under
`--bot` (test-pinned: `Cli.parse` without the flag yields no `:bot` key,
so the guarded print site cannot fire; banner format unit-pinned).
Held actions are a pure function of (seed, sampled tick sequence) —
same seed + same peer ⇒ same episode, so a desync bundle is
re-runnable from its logs. Seed absent → `App::Cli.new_seed` (printed).

## D3 — save quarantine (the law that makes this shippable)

New order-free modifier `--save <path>` (solo/host lanes) overrides the
save file. **`--bot` in a save-owning role (solo or `--host`) REFUSES
to start without `--save`** — parse-level `ArgumentError`, named
functional-plain text, exit 1 via the existing abort path. `--join
--save` refuses (F2: the joiner never keeps the save — mirrors
`--join --fresh`). `--bot-ticks` without `--bot` refuses. Default path
untouched when the flag is absent (pinned: existing parse hashes stay
byte-identical). Bots cannot touch `saves/world.json` by construction;
the orchestrator additionally md5-checks the real save before/after
every run and hard-fails on drift.

## D4 — log quarantine

The soak invokes `ruby -Isrc src/main.rb` DIRECTLY, stdout+stderr
redirected to `tmp/soak/<run>/ep<N>/{host,joiner}.log`. `bin/play*`
(which logs to `%TEMP%` and belongs to humans) is untouched — zero new
`game_two_session_*.log` from any soak path, verified at close.

## D5 — layout

- `src/app/autopilot.rb` — runtime code behind the flag (~70 lines);
  window hook ≤ ~20 lines (orchestrator cap 300 holds, `line_caps_test`).
- `soak/run_soak.sh` + `soak/chain_check.rb` — top-level `soak/`, NEVER
  under `harness/` (`wall_pin_test` bans persistence tokens there; the
  wall stays single-player).
- Episode artifacts → `tmp/soak/<run>/<ep>/` (tmp/ already gitignored).
- `rake soak [N=] [TICKS=] [SEED=]`; AGENTS.md gets one Commands bullet
  + one Layout line.

## D6 — episode protocol (Half-A-SHAPED rehearsal on scratch data)

Host bot + joiner bot over loopback (Tailscale later): host quits at
TICKS+120 (margin so BOTH seats clear TICKS — seats run ~D apart),
joiner backstop-quits at TICKS+3720. Per episode the checker asserts
from LOGS + exit codes only (never process liveness): `reason=quit`
both seats · `desyncs=0` both · ticks ≥ TICKS both · exit 0 both ·
AUTOPILOT banner present in both. Across episodes: host `persist
loaded digest` == previous `persist saved digest` (ep1 on scratch =
honest `fresh source=fresh`), joiner `loaded … source=handshake`
digest == host's digest whenever a save rode the wire (fresh ep1 ⇒ NO
joiner persist line, asserted), `sessions=` +1 per episode (1,2,3…).
These rehearse the SHAPE of Half A; the spec's arbiter stays CLOSED,
human-session-only — soak green changes nothing about the SEVENTEENTH.

## D7 — fault posture

Desync (>0 anywhere) or exit 1 or chain break → HARD FAIL, episode
bundle stays in `tmp/soak/<run>/` (logs, seeds in banners, save chain,
any `tmp/netplay/` artifact), investigate before anything ships. Exit
2 (link fault): hard fail on loopback (a loopback conn_lost is a real
anomaly); on Tailscale runs `ALLOW_LINK_FAULTS=1` records it as a
finding + observes rejoin behavior, chain expectation moves to
last-successful-saved. Stall/timeout → seats killed, episode reported
`timeout`, hard fail. Fix-vs-record routing: netplay/persistence
defects = open v18 lanes, fixed via TDD in their own commits;
anything design-flavored (pacing, feel, bot realism) = RECORDED, never
fixed inline.

## Cross-machine mode (Job 4 seam, built-in but conditional)

`HOST_ONLY=1` / `JOIN_ONLY=1 HOST_ADDR=<ip>` spawn a single seat; the
checker runs single-side (missing peer log = named SKIP finding, not a
pass). Junior's seat gets a pt-br runsheet + seat-addressed CHECKPOINT
note IF his machine is reachable this session; otherwise loopback
evidence suffices and the cross-machine burst is the standing next
step, owner-paced.
