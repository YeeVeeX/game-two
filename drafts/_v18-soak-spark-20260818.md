## Job 1 — design brief, decisions close here (~30 min)

`drafts/_v18-soak-brief-20260818.md`, short. Positions to take (dev
recommendation, cite the constraint that forces each):

- **D1 input injection:** in-process autopilot feeding the existing
  input abstraction (`src/core/input.rb` family), enabled per seat by
  CLI flag `--bot [seed]`. Never OS-level input (memorized Windows
  focus traps; hidden windows must still play). Policy: dumb seeded
  RNG — weighted movement with persistence, periodic
  attack/dodge/special/interact/mark, Esc at target tick. NOT
  gameplay AI; zero skill tuning; iteration cap = it moves, fights,
  and quits cleanly.
- **D2 determinism of an episode:** seed printed at start (one
  `AUTOPILOT seed=<n> quit_tick=<n>` line, gated behind `--bot`,
  test-pinned absent otherwise); policy reads only seeded RNG + local
  sim state so a desync episode is re-runnable from its bundle.
- **D3 save quarantine (the law that makes this shippable):** new CLI
  `--save <path>` overrides the save file. **`--bot` in a save-owning
  role (solo or `--host`) REFUSES to start without `--save`** — named
  refusal, exit 1, wording functional-plain. Joiner `--bot` needs no
  `--save` (F2: the joiner never keeps the save). Default path
  test-pinned unchanged when the flag is absent. Bots must be unable
  to touch `saves/world.json` by construction.
- **D4 log quarantine:** soak launches write logs under `tmp/soak/`
  ONLY (dedicated launcher/orchestrator — not `bin/play.cmd`, which
  logs to `%TEMP%` and belongs to humans). Zero new
  `game_two_session_*.log` in temp dirs from any soak path — verified
  at close.
- **D5 layout:** autopilot = `src/app/autopilot.rb` (runtime code
  behind a flag; window.rb hook stays tiny — ≤300-line cap holds).
  Orchestrator + chain checker = new top-level `soak/` (`run_soak.sh`,
  `chain_check.rb`) — NEVER under `harness/` (`wall_pin_test` bans
  persistence tokens in `harness/**/*.rb`; the wall stays
  single-player). Episode artifacts → `tmp/soak/<run>/<ep>/`
  (gitignored). AGENTS.md gets one Layout line + one Commands bullet
  (`rake soak`).
- **D6 episode protocol:** host bot + joiner bot over loopback (and
  later Tailscale), play ≥ target ticks, autopilot presses Esc, clean
  quit saves scratch world; orchestrator asserts per episode:
  `reason=quit` both seats, `desyncs=0`, ticks ≥ target, exit 0; and
  across episodes: `persist loaded digest` == previous `persist saved
  digest`, `sessions=` +1 per episode. These are Half-A-SHAPED
  invariants on scratch data — a rehearsal, explicitly NOT the
  arbiter (the spec's arbiter stays CLOSED, human-session-only).
- **D7 fault posture:** desync or exit 1 → hard fail, bundle the
  episode (logs, seeds, save chain, `tmp/netplay/` artifact),
  investigate; exit 2 (link fault) → recorded finding + rejoin
  behavior observed, not a hard fail on Tailscale runs; stalls
  reported per episode.
