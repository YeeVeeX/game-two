## Problem killed

`opens` was consumed BLIND everywhere downstream of load:

- `world.rb` `interact_seal` (~1321-1337): `opens = station[:opens]` →
  `breached?` → `spend_banked` → `restore_breach!` — an ill-shaped
  `opens` (nil / string pair / float / 3-element) or a legal-shaped one
  naming NO transition **burned the toll**, opened nothing visible, and
  **persisted the inert fact into the save** at clean quit.
- `price_sheet.rb:29` fed `station[:opens]` to the breached callback
  pre-breach (price display path).
- The save side was already guarded (`save_state.rb:166-176`
  breached-vs-opens cross-check at restore); the ZONE side (load time)
  was the missing half. The s32 tile-shape guard never saw `opens` (it
  doesn't route through `check_passable!`).

Reviewer's sharpening (banked): a nil-opens seal was never workable
even before this law — the toll burns, then `restore_breach!(@zone_name,
nil)` persists `[zone, nil]`, which SaveState's breached cross-check
REFUSES at the NEXT load. Pre-guard behavior was toll-eater **plus
save-poisoner**, not a feature.

## What shipped

`TileMap#validate_seal_opens!` (private, called from `validate!` after
station passability): for each station with `type == "seal"` —

1. **Shape** via `tile_pair?` — the s32 predicate EXTRACTED so
   `check_passable!` and this law share ONE copy (never drift two):
   `"seal at [x, y]: opens must be an [x, y] tile (got …)"`.
2. **Bounds** (0 ≤ x < cols, 0 ≤ y < rows) — a coordinate typo off the
   map reads differently from a missing Transition entity:
   `"seal at [x, y]: opens [9, 9] outside 5x5 map"`.
3. **Semantics** — `transition_at(*opens)` must hit:
   `"seal at [x, y]: opens [3, 3] names no transition (the toll would
   open nothing)"`.

All refusals class **BadMap** (house style), each carrying the seal's
`at` + the `opens` value. `check_passable!` behavior byte-identical
(reviewer diffed against `38ae352`).
